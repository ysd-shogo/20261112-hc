このサイトについて

この世界には数多くの陰謀論や都市伝説があります。当サイトでは、日本をはじめとする世界各地の都市伝説や陰謀論をまとめたサイトになっております。飲み会や雑談時に使えるような話題を提供します。
※このサイトはフィクションです。現実の団体、人物とは一切関係がありません。

陰謀論とは

社会で起きた重大な事件や現象（戦争、経済危機、災害、著名人の死など）の背後に、「特定の悪意ある隠された組織や権力者（秘密結社、政府、巨大企業など）による意図的な陰謀がある」と説明する説のこと

都市伝説とは

現代の口承文芸（口伝えの噂話）の一種で、あたかも実際にあったことのように、都市部や現代社会を舞台として人から人へと語り継がれる奇妙なストーリーのこと
